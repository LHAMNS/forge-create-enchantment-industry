## Welcome to **Create: Enchantment Industry** (Forge 1.20.1 Port)
A mod offering more tools and methods to handle experience & enchantment in Create.

This is a **Forge 1.20.1 port** of [Create: Enchantment Industry](https://github.com/DragonsPlusMinecraft/CreateEnchantmentIndustry) by [DragonsPlus](https://github.com/DragonsPlusMinecraft), based on the upstream `1.20.1/6.0.0-dev` branch (v1.3.3) with all new features from the NeoForge 1.21.1 version backported.

## Features (ported from 1.21.1)
- **Super Experience Block / Nugget** - Upgraded experience storage, obtained via lightning strike
- **Experience Hatch** - Player XP deposit/withdrawal into fluid tanks
- **Experience Lantern** - Auto-absorbs nearby player XP, supports contraption movement
- **Mechanical Grindstone + Grindstone Drain** - Automated enchantment grinding with fluid output
- **Blaze Forger** - Automated anvil consuming experience fluid
- **Enchanting Templates** - Normal & super variants for the Blaze Enchanter
- **Deployer XP Extension** - Kill drops, mending, nugget conversion
- **New Printer Entries** - Banner pattern, custom name, address, package pattern printing
- **Mechanical Arm Integration** - For both Enchanter and Forger
- **JEI Grinding Category** - Recipe display for grindstone

## Bug Fixes
10 upstream bugs fixed, including a **critical experience duplication exploit** in FurnaceExpExtractor.
