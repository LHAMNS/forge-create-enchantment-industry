## Create: Enchantment Industry 1.3.4

### Bug Fixes
- Fixed enchanted books using wrong NBT tag (Enchantments vs StoredEnchantments) across Disenchanter, Grindstone, Blaze Forger, and Blaze Enchanter
- Fixed Blaze Forger renderer showing duplicate/stale floating items after forging completes
- Fixed Blaze Forger processing animation being static on clients (no bobbing during forging)
- Fixed Grindstone treating enchanted books as unenchanted during merge and curse-stripping
- Fixed Disenchanter writing curses to wrong tag on enchanted book results
- Fixed Printer crashing when copy target has no matching PrintEntry (e.g. mod removed)
- Fixed Ponder scenes writing enchantments to wrong tag for enchanted books

### Improvements
- Added shared enchantment read/write helpers (getAllEnchantments/setAllEnchantments) for consistent StoredEnchantments handling
- Added missing Create block tags, lang entries, and BlazeForger renderer from upstream
- Ported 3 missing cake recipes from upstream
