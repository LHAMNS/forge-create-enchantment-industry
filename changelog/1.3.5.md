## Create: Enchantment Industry 1.3.5

### Critical Fixes
- Fixed item duplication exploit: breaking Blaze Forger during processing no longer drops preview slot copies

### Bug Fixes
- Fixed fuel consumption waste: Enchanter and Forger now reject fuel items when tank can't fit the full amount
- Fixed Blaze Forger special fuel being unusable: hyper() now checks superExperience counter
- Fixed Blaze Enchanter infinite idle loop when superExperience > 0 but tank has normal XP
- Fixed Forger consumeExperience falling back to normal XP when hyper mode is triggered by superExperience
- Fixed Grindstone Drain only dropping first output stack on block break (remaining items were lost)
- Fixed FurnaceExpExtractor phantom drains consuming recipe entries but producing 0 mB fluid
- Fixed 4 block entities using invalidate() instead of invalidateCaps() for capability lifecycle
- Fixed publishMods incorrectly marking jar for both forge and neoforge platforms

### Improvements
- Registered Experience Cake (1000 XP) and Experience Cake Slice (250 XP) as special fuel
- Registered Mending and Infinity enchantments with super-tier cap override (extension=0)
- Added compatible XP fluid registration for cofh_core, cyclic, enderio, industrialforegoing, mob_grinding_utils, pneumaticcraft, sophisticatedcore
- Banner pattern printing now accepts dye fluids (forge:dyes tag) for color reprinting when CDP is installed
- Fixed gradlew CRLF line endings for WSL/Linux compatibility
